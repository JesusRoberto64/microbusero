# 🚌 Microbusero

**Microbusero** es un videojuego arcade en desarrollo donde tomas el control de un microbús y tratas de mantenerlo en movimiento mientras recorres el camino.

La idea es crear una experiencia sencilla, inmediata y divertida: un juego que puedas entender rápidamente, pero que poco a poco exija mejores reflejos y control del vehículo.

Está pensado principalmente como un juego arcade para jugar por diversión entre amigos y familia.

---

## 🎮 Concepto

Conduce el microbús, mantén el control y trata de llegar cada vez más lejos.

**Microbusero** busca recuperar una filosofía muy sencilla de los juegos arcade:

* controles fáciles de entender;
* partidas rápidas;
* dificultad progresiva;
* intentar superar tu mejor desempeño;
* y, sobre todo, tener ganas de jugar **una partida más**.

El proyecto todavía se encuentra en desarrollo, por lo que las mecánicas, escenarios y presentación pueden cambiar conforme avance.

---

## 🕹️ Controles

| Acción               | Tecla |
| -------------------- | ----- |
| Girar a la izquierda | `A`   |
| Girar a la derecha   | `D`   |

Más controles serán añadidos conforme se desarrollen las mecánicas del juego.


## 🛠️ Tecnología

El proyecto está desarrollado con:

* **Godot Engine 4.6**
* **GDScript**
* Renderizador **Mobile**

---

## 📂 Estructura del proyecto

```text
microbusero/
├── Arte/        # Recursos gráficos del juego
├── Escenas/     # Escenas de Godot
├── Logica/      # Scripts y comportamiento del juego
├── project.godot
└── LICENSE
```

La intención es mantener separados los recursos visuales, las escenas y la lógica para que el proyecto sea fácil de explorar y modificar.

---

## 🚀 Ejecutar el proyecto

Necesitas una versión compatible de **Godot 4.x**.

Clona el repositorio:

```bash
git clone https://github.com/JesusRoberto64/microbusero.git
```

Entra a la carpeta:

```bash
cd microbusero
```

Después abre `project.godot` desde Godot Engine y ejecuta la escena principal con:

```text
F6 / F5
```

o usando el botón **Run Project** del editor.

---

## 🎯 Objetivo del proyecto

Más que realizar una simulación realista de conducción, **Microbusero** busca convertir la idea de manejar un microbús en una experiencia exagerada y arcade.

El objetivo es experimentar con mecánicas sencillas, físicas, obstáculos y situaciones que puedan producir partidas caóticas, cortas y rejugables.
